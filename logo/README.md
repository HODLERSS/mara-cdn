# MARA logo — light / dark-mode variant

`MARA-MAIN-LOGO-Light.svg` is a drop-in replacement for the production asset

    https://cdn.prod.website-files.com/660480da92276a998660043d/687ae80238d128f9d3ead940_MAIN-LOGO.svg

Identical geometry, viewBox and gold rule; the wordmark fill is changed from
`#272525` (MARA "Nite") to `#EEECE8` (MARA "Lite") so it is legible on dark
backgrounds. The gold rule stays `#F2A900` in both variants.

| Background | Use |
|---|---|
| light | the existing `MAIN-LOGO.svg` (`#272525`) |
| dark  | `MARA-MAIN-LOGO-Light.svg` (`#EEECE8`) |

PNG renditions are transparent-background, 300:95 aspect, at 128/256/512/1024/2048 px wide.
Prefer the SVG; the PNGs exist for contexts that cannot take vector.

Source of the light colour: MARA Branding Package, `Logos/MARA/Logo/MARA-Logo-Lite`.
